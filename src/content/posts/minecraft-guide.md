# Minecraft 完全指南：从入门到精通

:::note[什么是 Minecraft？]
Minecraft 是由 Mojang Studios 开发的沙盒游戏，自 2011 年正式发布以来，已成为全球销量最高的电子游戏之一。玩家可以在一个由方块组成的三维世界中自由探索、采集资源、合成物品、建造建筑，以及与各种生物互动。

## 游戏模式

Minecraft 提供多种游戏模式，每种模式带来截然不同的体验。

| 模式 | 描述 | 生命值 | 饥饿 | 可破坏方块 | 可放置方块 |
| --- | --- | --- | --- | --- | --- |
| 生存模式 | 采集资源、合成物品、对抗怪物 | ✅ | ✅ | ✅ | ✅ |
| 创造模式 | 无限资源、自由飞行、无敌状态 | ✅（无敌） | ❌ | ✅ | ✅ |
| 冒险模式 | 用于自定义地图，限制方块操作 | ✅ | ✅ | 受限 | 受限 |
| 极限模式 | 生存模式的硬核版本，只有一条命 | ✅（永久死亡） | ✅ | ✅ | ✅ |
| 观察模式 | 自由飞行、穿墙观察，不可交互 | ❌ | ❌ | ❌ | ❌ |

:::tip[新手建议]
如果你是第一次接触 Minecraft，建议从**生存模式**开始。它能让你完整体验游戏的核心玩法循环：探索 → 采集 → 合成 → 建造 → 战斗。
:::

## 新手生存指南

### 第一天：从零开始

Minecraft 的第一天至关重要。你需要在天黑之前完成基本的生存准备，因为夜晚会刷新敌对生物。

**时间线概览：**

1. **出生后立刻**：徒手破坏树木，获取原木（至少 10 个）
2. **第 1-2 分钟**：合成工作台，制作木镐
3. **第 3-5 分钟**：用木镐挖掘石头，制作石制工具
4. **第 5-10 分钟**：寻找食物来源（动物、农作物）
5. **第 10-15 分钟**：寻找或挖掘简易庇护所
6. **日落前**：用火把照亮周围，封住入口

> ⚠️ **重要提示**：永远不要向下挖掘你脚下直接的方块。你可能会掉入岩浆、深坑或怪物巢穴中。

### 基础合成配方

以下是生存初期最重要的合成配方：

```
木镐          石镐          铁镐
[][][]        [][]          [][] 
 _X_          _X_           _X_
 _I_          _I_           _I_

木棍 = 木板 + 木板（竖直排列）
工作台 = 4 个木板（2×2）
熔炉 = 8 个鹅卵石（围成一圈）
```

## 合成与工具

### 工具等级

Minecraft 中的工具分为多个材质等级，每级的耐久度和挖掘速度都有显著提升：

```yaml
工具材质等级（从低到高）:
  木制:   耐久 59    - 基础工具
  石制:   耐久 131   - 早期实用
  铁制:   耐久 250   - 中期主力
  钻石:   耐久 1561  - 后期标配
  下界合金: 耐久 2031  - 最终升级
```

:::tip[效率对比]
钻石镐挖掘石头需要 0.3 秒，而木镐需要 1.15 秒。在大规模挖掘时，工具等级的差异会累积成巨大的时间差距。
:::

### 盔甲防护值

| 盔甲类型 | 头盔 | 胸甲 | 护腿 | 靴子 | 总防护值 |
| --- | --- | --- | --- | --- | --- |
| 皮革 | 1 | 3 | 2 | 1 | 7 |
| 锁链 | 2 | 5 | 4 | 2 | 13 |
| 铁 | 2 | 6 | 5 | 2 | 15 |
| 钻石 | 3 | 8 | 6 | 3 | 20 |
| 下界合金 | 3 | 8 | 6 | 3 | 20（+击退抗性） |

> 下界合金盔甲与钻石盔甲拥有相同的防护值，但下界合金额外提供击退抗性，并且对岩浆和火焰伤害有天然抗性。

## 附魔系统

附魔是提升装备性能的重要系统。通过附魔台和铁砧，你可以为工具、武器和盔甲添加各种特殊效果。

### 附魔台机制

附魔台需要以下条件才能达到最大等级（30 级）：

```
附魔台布局（俯视图）：

        书架
    书架      书架
  书架          书架
    书架      书架
        书架

规则：
- 书架数量：15 个（最大效果）
- 书架与附魔台距离：1 格
- 中间不能有障碍物（火把也不行）
- 书架需要由书和木板合成
```

### 常用附魔推荐

:::code-group labels=[武器, 工具, 盔甲]

```text title="武器附魔"
锋利 V        → 增加近战伤害（+6.25 攻击力）
火焰附加 II   → 攻击目标着火
击退 II       → 增加击退距离
亡灵杀手 V    → 对亡灵生物额外伤害
经验修补      → 用经验球修复耐久
```

```text title="工具附魔"
效率 V        → 大幅提高挖掘速度
时运 III      → 增加方块掉落物数量
精准采集      → 掉落方块本身（而非分解物）
耐久 III      → 延长工具使用寿命
经验修补      → 用经验球修复耐久
```

```text title="盔甲附魔"
保护 IV       → 减少所有伤害
荆棘 III      → 对攻击者造成反伤
深海探索者 III → 提高水下移动速度
冰霜行者 II   → 在水上行走时结冰
经验修补      → 用经验球修复耐久
```

:::

### 附魔书获取途径

附魔书可以通过以下方式获得：

1. **钓鱼** — 低概率获得随机附魔书
2. **地牢宝箱** — 在各种结构的宝箱中发现
3. **村民交易** — 图书管理员村民出售附魔书
4. **附魔台** — 对书进行附魔
5. **袭击奖励** — 击败袭击事件后获得

## 红石基础

红石是 Minecraft 中的"电路系统"，允许玩家创建从简单机关到复杂计算机的各种装置。

### 基础红石元件

```text
红石粉      → 传输信号（最远 15 格）
红石火把    → 信号反转器（NOT 门）
红石中继器  → 延迟信号、防止信号衰减
红石比较器  → 比较信号强度
活塞        → 推动方块
粘性活塞    → 推动和拉回方块
侦测器      → 检测方块变化
发射器      → 发射物品或药水
漏斗        → 传输物品
```

### 常用逻辑门

红石可以构建各种逻辑门，它们是复杂红石机械的基础：

| 逻辑门 | 功能 | 红石实现方式 |
| --- | --- | --- |
| NOT（非） | 输入为开则输出关 | 红石火把 |
| AND（与） | 两个输入都为开时输出开 | 两个红石火把串联 |
| OR（或） | 任一输入为开时输出开 | 两条红石粉合并 |
| XOR（异或） | 仅一个输入为开时输出开 | 两个红石火把并联 |
| NAND（与非） | NOT + AND | 红石火把 + 两个输入 |

:::note[红石小知识]
红石信号强度为 0-15，每传播一格衰减 1 级。使用红石中继器可以将信号刷新为满强度（15），从而实现长距离传输。
:::

### 实用红石装置

**自动农场示例：**

```text
[水源] → [漏斗] → [箱子]
  ↓
[活塞] ← [红石时钟] ← [红石粉]
  ↓
[农作物区域]

工作原理：
1. 红石时钟产生周期性信号
2. 活塞推动水流冲刷成熟作物
3. 水流将作物冲向漏斗
4. 漏斗收集物品存入箱子
```

## 指令系统

Minecraft 的指令系统允许玩家通过输入命令来操控游戏世界。以下是一些常用指令。

### 基础指令

```bash
# 传送玩家到指定坐标
/tp @p 100 64 200

# 设置时间为白天
/time set day

# 切换游戏模式为创造
/gamemode creative @p

# 给予物品
/give @p diamond 64

# 设置天气为晴天
/weather clear

# 在指定位置放置方块
/setblock 100 64 200 minecraft:stone
```

### 选择器详解

| 选择器 | 含义 | 示例 |
| --- | --- | --- |
| `@p` | 最近的玩家 | `/give @p diamond` |
| `@a` | 所有玩家 | `/effect give @a speed 30` |
| `@r` | 随机玩家 | `/tp @r 0 64 0` |
| `@e` | 所有实体 | `/kill @e[type=zombie]` |
| `@s` | 命令执行者 | `/heal @s` |

### 实用指令组合

:::code-group labels=[建筑辅助, 批量操作, 自定义效果]

```bash title="建筑辅助"
# 填充区域（用石头填充 10×10×10 的区域）
/fill ~0 ~0 ~0 ~10 ~10 ~10 minecraft:stone

# 复制建筑结构
/structure save my_build ~ ~ ~ ~20 ~20 ~20
/structure load my_build 100 64 200

# 设置方块为屏障（不可见边界）
/fill ~ ~ ~ ~50 ~10 ~50 minecraft:barrier hollow
```

```bash title="批量操作"
# 杀死所有僵尸
/kill @e[type=zombie]

# 清除所有掉落物
/kill @e[type=item]

# 给所有玩家施加夜视效果（5 分钟）
/effect give @a night_vision 600

# 在指定半径内清除怪物
/kill @e[type=!player,distance=..50]
```

```bash title="自定义效果"
# 生成带有自定义名称的生物
/summon zombie ~ ~ ~ {CustomName:'{"text":"Boss Zombie"}',Health:100}

# 生成带有附魔武器的骷髅
/summon skeleton ~ ~ ~ {HandItems:[{id:"bow",Count:1,tag:{Enchantments:[{id:"power",lvl:5}]}}]}

# 创建计分板目标
/scoreboard objectives add deaths deathCount
/scoreboard objectives setdisplay list deaths
```

:::

:::warning[指令使用注意]
在多人服务器中，指令通常需要管理员权限（OP）。滥用指令可能破坏其他玩家的游戏体验。请在单人世界或私人服务器中练习。
:::

### 建筑技巧

> 🏗️ **比例是关键**：在开始建造前，先确定好比例。玩家角色高 2 格，所以门至少要 3 格高才显得自然。

1. **使用对比材质** — 不要只用一种方块，混合使用 2-3 种材质增加层次感
2. **添加深度** — 墙面不要做平的，使用楼梯、半砖和活板门创造凹凸感
3. **注重光影** — 合理使用火把、灯笼和萤石，创造氛围
4. **景观配合** — 建筑周围种植树木、花朵，铺设路径
5. **内部装饰** — 不要只注重外观，内部的家具和装饰同样重要

## 多人游戏

### 服务器类型

| 类型 | 描述 | 适合人群 |
| --- | --- | --- |
| 生存服务器 | 多人合作生存，通常有领地保护 | 喜欢合作的玩家 |
| 创意服务器 | 自由建造，通常有 WorldEdit 插件 | 建筑爱好者 |
| 小游戏服务器 | 提供各种小游戏（空岛战争、饥饿游戏等） | 竞技玩家 |
| 空岛服务器 | 从一座小岛开始，挑战极限生存 | 喜欢挑战的玩家 |
| RPG 服务器 | 自定义地图、任务、职业系统 | 角色扮演爱好者 |
| 模组服务器 | 安装 Forge/Fabric 模组，扩展玩法 | 追求新体验的玩家 |

### 服务器常用指令

```bash
# 设置家的位置
/sethome base

# 传送到家
/home base

# 传送到其他玩家（需对方同意）
/tpa <玩家名>

# 领地保护
/res create <领地名>

# 查看在线玩家
/list

# 私聊
/msg <玩家名> <消息内容>
```
